i Loads files exactly as authored, with no auto-centering or auto-orientation — use this for scans that already share one coordinate system (e.g. matched upper/lower jaw exports, or a scan plus its temp restoration) so they stay correctly positioned relative to each other. This turns on automatically whenever you select or drop more than one file at once; turn it on here first if you're adding files to an already-aligned set one at a time. Single files loaded individually are still auto-centered and auto-oriented by default, which is usually better for inspecting one file on its own.
